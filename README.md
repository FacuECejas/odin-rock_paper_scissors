# Project: Rock Paper Scissors

This is a project for The Odin Project's 'JavaScript Basics' Course.

In this project you can play Rock Paper Scissors against the computer. All results are displayed in the console.
If you want to play, just open the console and type `playGame()`.

In this project I exercised basic JavaScript concepts such as:
- Variables, Scope, Data Types, and Operators
- Functions
- Conditional Statements
- Loops
