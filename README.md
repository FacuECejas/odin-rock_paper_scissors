# Project: Rock Paper Scissors

This is a project for The Odin Project's 'JavaScript Basics' Course.

In this project you can play Rock Paper Scissors against the computer.

In this project I exercised basic JavaScript concepts such as:
- Variables, Scope, Data Types, and Operators
- Functions
- Conditional Statements
- Loops

I then revisited the project to refactor the code and implement an UI to play the game, exercising DOM manipulation and event handling.

In the new version I no longer use the console to play, nor do I use loops or the prompt function.

I also had some practice with branching and merging in Git.
